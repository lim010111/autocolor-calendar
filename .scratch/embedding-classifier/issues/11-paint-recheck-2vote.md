### 2026-08-12 — logprobs 프로브: confidence 게이트 실현 가능성 실측 확인

3자 리뷰 대안("2표는 확신도를 재표집으로 사는 가장 비싼 방법 — logprobs 는
1콜로 같은 신호")의 전제를 실측
(`.scratch/embedding-classifier/spike/logprobs-probe.ts`, v8, ~38콜):

**Q1/Q2 — 지원 확인.** `logprobs`/`top_logprobs` 모두 HTTP 200 + **응답에
실제 토큰별 logprobs 포함**. temperature/seed 의 "수용 후 무시"(07-28
sampling-probe)와 달리 진짜로 동작한다.

**Q3 — 분별력.** 익명화 회귀 4건 + 칠하기 케이스 2건, 각 6콜:

| 케이스 | 판정 | 답 토큰 lp | 차점 후보 lp | 성격 |
|---|---|---|---|---|
| 알뜰폰 요금제 | none 6/6 | −0.00 | 개 −11.9 | 명확 none |
| 호흡 명상 수업 | none 6/6 | −0.00 | 운 −13.5 | v8 이 안정화 |
| 한올물류 입사 지원 | none 6/6 | −0.06 | **개 −2.8** | 역사적 난건 — 확신 저하 가시 |
| 등, 가슴 근력운동 | 운동 6/6 | −0.00 | none −9.9 | 명확 칠하기 |
| **개발 서적 읽기** | **none 5/6 · 개발 1/6** | −0.13~−0.24 | **개 −1.6** | **실제 flip + 저확신 일치** |

명확 케이스는 차점 후보가 −9~−16(확률 <0.01%), 경계 케이스는 −1.5~−2.8
(6~21%)로 **간격이 한 자릿수 nat 차이로 갈린다**. 특히 이번 프로브에서
실제로 flip 한 케이스("개발 서적 읽기" 1/6 칠하기)의 그 칠하기가 Σlp
−1.86 저확신으로 관측됨 — **재표집(2표)이 잡는 흔들림을 단일 콜 logprobs
가 같은 지점에서 본다**는 방향 증거. "추론 경로 분산은 단일 콜이 못 본다"
는 이론적 우려는 이 표본(n=6)에서는 반증 방향.

**함의**: confidence 게이트(예: 답 토큰 lp 문턱 또는 차점 간격 문턱)는
기술적으로 실현 가능. 단 채택 결정은 별도 측정 필요 — 기존 콜 테이블에는
logprobs 가 없으므로, logprobs 기록 런을 추가해 "confidence 게이트 vs
2표"를 같은 데이터로 짝비교(문턱 스윕 포함)한 뒤 교체/하이브리드(고확신
즉시 칠 + 저확신만 확인 콜, 배율 1.0~1.2)를 판정한다. 그 전까지 본 이슈의
2표 설계는 유지(실측 완료된 안전값).
